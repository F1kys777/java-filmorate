## Реализованная функциональность

В рамках командного проекта была добавлена следующая функциональность.

### 1. Режиссёры фильмов
Добавлена информация о режиссёрах и возможность получать фильмы конкретного режиссёра.

Возможности:
- Привязка режиссёров к фильму.
- Вывод всех фильмов режиссёра с сортировкой:
  - по количеству лайков;
  - по году выпуска.

Эндпоинты:
- `GET /directors` — список всех режиссёров.
- `GET /directors/{id}` — получение режиссёра по id.
- `POST /directors` — создание режиссёра.
- `PUT /directors` — изменение режиссёра.
- `DELETE /directors/{id}` — удаление режиссёра.
- `GET /films/director/{directorId}?sortBy={year|likes}` — фильмы режиссёра с сортировкой.
- `POST /films`, `PUT /films` — добавление и обновление фильма с полем `directors`.

### 2. Поиск фильмов
Реализован поиск по подстроке в названии фильма и/или в имени режиссёра.

Особенности:
- Поиск нечувствителен к регистру.
- Возможен поиск одновременно и по названию, и по режиссёру.
- Результаты отсортированы по популярности (количеству лайков).

Эндпоинты:
- `GET /films/search?query={text}&by={title|director|title,director}`

### 3. Общие фильмы
Реализован вывод фильмов, которые одновременно понравились двум пользователям.

Особенности:
- Список отсортирован по популярности.
- Отдаются только те фильмы, у которых есть лайки от обоих пользователей.

Эндпоинты:
- `GET /films/common?userId={userId}&friendId={friendId}`

### 4. Удаление фильмов и пользователей
Добавлена возможность удаления сущностей по идентификатору с корректной обработкой связанных данных.

Эндпоинты:
- `DELETE /users/{userId}` — удаление пользователя.
- `DELETE /films/{filmId}` — удаление фильма.

При удалении пользователя каскадно удаляются его лайки, дружбы и отзывы.
При удалении фильма — его лайки, жанры, режиссёры и отзывы.

### 5. Рекомендации фильмов
Реализована простая рекомендательная система на основе пересечения лайков.

Алгоритм:
1. Находятся пользователи с максимальным пересечением по лайкам.
2. Определяются фильмы, которые один пользователь пролайкал, а второй — нет.
3. Пользователю рекомендуются фильмы, которые понравились пользователям с похожими вкусами и которые он сам ещё не оценил.

Эндпоинты:
- `GET /users/{id}/recommendations`

### 6. Отзывы на фильмы
Добавлена система отзывов с рейтингом полезности.

Характеристики отзыва:
- тип: положительный / отрицательный;
- рейтинг полезности `useful` — увеличивается на 1 за лайк и уменьшается на 1 за дизлайк;
- у одного пользователя — не более одного отзыва на фильм.

Эндпоинты:
- `POST /reviews` — создание отзыва.
- `PUT /reviews` — редактирование отзыва.
- `DELETE /reviews/{id}` — удаление отзыва.
- `GET /reviews/{id}` — получение отзыва по id.
- `GET /reviews?filmId={filmId}&count={count}` — отзывы по фильму с сортировкой по полезности (по умолчанию `count=10`).
- `PUT /reviews/{id}/like/{userId}` — поставить лайк отзыву.
- `PUT /reviews/{id}/dislike/{userId}` — поставить дизлайк отзыву.
- `DELETE /reviews/{id}/like/{userId}` — снять лайк.
- `DELETE /reviews/{id}/dislike/{userId}` — снять дизлайк.

### 7. Лента событий
Реализована лента последних событий пользователя: добавление/удаление из друзей, лайки, отзывы.

Особенности:
- Каждое событие хранится в отдельной таблице `FeedEvents`.
- Событие содержит: `timestamp`, `userId`, `eventType` (`LIKE`, `REVIEW`, `FRIEND`), `operation` (`ADD`, `UPDATE`, `REMOVE`), `entityId`.
- Лента отдаётся по возрастанию `eventId`, что соответствует хронологии действий.

Эндпоинты:
- `GET /users/{id}/feed`

### 8. Популярные фильмы с фильтрацией по жанру и году
Сделали вывод топ-N фильмов по лайкам. Можно дополнительно отфильтровать по жанру и по году выпуска.

Параметры:

1. count — сколько фильмов вывести (по умолчанию 10);

2. genreId — id жанра;

3. year — год выпуска.

Эндпоинт:

GET /films/popular?count={limit}&genreId={genreId}&year={year}
